## 5. 「구매 계획 생성기」 로직 요약

**입력**: 예산(기본 4,000,000원, step 100,000) · 모둠 수(기본 7, 1~12) · 구성 방침(프리셋 8종) · 수업 체크박스 26개(기본 체크 = 필수 추천 8건). 수업 선택 버튼: 전체 / 해제 / 중1만 / 중2만 / 중3만 / 필수 추천.

**프리셋과 라인 우선순위** (라인 인덱스: 0 이지 유선, 1 이지 나노, 2 사이언스큐브 무선, 3 버니어, 4 파스코). 센서별로 우선순위 순서대로 훑어 **가격이 null이 아닌 첫 라인**을 채택:
- 혼합(권장) `mix`: [0,2,1,3,4]
- 무선 우선 `wireless`: [2,1,4,3]
- 가성비 우선 `cheap`: [0,1,2,3,4]
- 정밀도 우선 `premium`: [4,3,2,1,0]
- 한 업체로만: `only_ez` [0,1] / `only_sc` [2] / `only_vn` [3] / `only_ps` [4] — 그 업체에 없는 센서는 "○○ 미취급" 행(금액 0)으로 남고 "다른 업체에서 채우기…" 셀렉트 제공
- 우선순위 목록에서 못 찾으면(한 업체 모드 제외) 아무 라인이나 첫 non-null로 폴백

**수량 규칙**: 센서 종류별 필요 개수 = 선택 수업들의 동시 사용 개수 **최댓값**(합계 아님). 세트 수 = 전 모둠(`full`=모둠 수) / 2모둠당 1(`half`=ceil(모둠/2)) / 시연 1세트(`demo`=1). 수량 = 동시개수 × 세트 수.

**이지메이커 필수 부품 자동 추가**: 유선 라인이 하나라도 있으면 메인보드 = 유선 센서들의 세트 수 **최댓값**(60,000원). 나노 라인은 나노보드(55,000) + 일체형 배터리(11,000)를 **나노 센서 수량 합계만큼**.

**사용자 조정**: 센서마다 판매사 셀렉트로 직접 변경(최저가에 "(최저)" 표시, 프리셋을 바꾸면 개별 선택 초기화) · ✕로 이미 보유 품목 제외(제외 항목은 보드 산정에서도 빠짐) · 스케일 3단 버튼.

**출력**: 예상 총액, 예산 대비 %·막대, 판매사별 합계, 여유/초과 안내(초과 시 가장 큰 항목을 지목하며 "2모둠당 1/시연 1세트" 권유), 하단 고정 바. 내보내기: 정산서 CSV(서울시교육청 「지능형 과학실 환경 구축 사업 정산서」 나. 사업별 집행 내역 9열 — 구분·항목·품명·규격, 세부 산출 내역·단가(천원)·수량·지출액(천원)·재원·비고 / 구분=필수, 항목=⑥AI수업기자재, 재원=교육청, 비고=라인명+S2B 번호, 천원 단위, 엑셀 13행부터 붙여넣기, 파일명 `센서구매_정산서집행내역_N모둠_YYYYMMDD.csv`) · 목록 복사 · 인쇄/PDF.

## 6. 발견한 내부 불일치·주의점

1. **영상 편수**: 탭1(업체 비교)은 버니어를 "한국어 영상 **90여 편**"으로 소개하지만, 실제 수록은 **41편**(7+16+12+4+2, 배열 실측 일치). 히어로 배지·업데이트 이력은 "41편". 90여 편은 채널 전체 규모, 41편은 골라 담은 수 — 구분 없이 읽으면 혼동됨. 또한 41편 중 2편은 한국과학 채널이 아닌 "다른 선생님이 만든 영상"(보또보과학, 강인숙 선생님)인데 JS 주석은 "한국과학 채널, 전부 유효 확인"이라고만 적음.
2. **MBL 수업허브 실험 수 산수 오류**: "38건 (30건 + 10건에서 중복 7건 병합)" → 30+10−7 = **33**, 38이 아님.
3. **서울시교육청 자료집 건수**: 탭1은 사이언스큐브 매뉴얼을 "서울시교육청 자료집에 수업 사례 **5건**"이라 쓰지만, 이 페이지가 자료집 쪽수를 매핑한 수업은 **10건**이고 수업허브 설명도 "자료집 10건". (5건이 '사이언스큐브를 쓴 사례만'인지 설명 없음.)
4. **이지메이커 30건 vs 매핑 28항목**: 사례집은 실험 30건이라 하나, REFS에 매핑된 이지메이커 자료집 항목은 28개(수업 23건에 분산). 나머지 2건은 페이지에 없음.
5. **파스코 25종 vs 링크 22개**: 중학 실험 25종이라 소개하나 개별 E-BOOK 링크는 고유 22개.
6. **S2B 번호 자릿수 이상**: 사이언스큐브 포토게이트 `20220344034768`만 **14자리**(나머지 22개는 15자리). 같은 등록 묶음(202203244034xxx) 패턴으로 보아 `2022032440347 68` 중 '2' 한 자리 누락 오타 가능성 — 품의 전 카탈로그 대조 필요(추정이며 확인 안 됨).
7. **"전 품목 S2B 등록"(파스코) vs 실제 수록 14개**: 파스코 S2B 번호는 14개 키만 있고(전압·전류·산소·운동·열전대·용존산소 없음) 화면에는 표시되지 않고 CSV 비고에만 들어감.
8. **가격대 문구와 가격표 상한 불일치**: 버니어 "20.7만~**139만원**"·파스코 "20.7만~**116.2만원**"이라 하나 가격표의 최고가는 버니어 678,000 / 파스코 875,000 — 상한에 해당하는 제품이 표에 없음(표 밖 제품 기준으로 보임). 사이언스큐브 "11만~99만원"(990,000 용존산소)과 이지메이커 "1.5만~15.4만원"(나노 CO₂·pH 154,000)은 표와 일치.
9. **시각·청각 자극 반응 시간의 센서**: 본문(탭1·탭2)은 "DIY-B 센서 **2개**로 시각·청각 자극 반응 시간 측정"이라 하는데, LESSONS 데이터는 이 수업의 필요 센서를 **소리 ×1**로 등록(DIY-B=전도도 키 `cond` 미포함). 생성기 수량도 이에 따라 계산됨.
10. **학년 표기 불일치**: '수권의 층상 구조 만들기'는 **중2**(수권과 해수, [9과18-02])로 분류돼 있으나 연결된 파스코 문서 제목은 "**[중3]** 해수의 연직 수온분포". (성취기준 번호 순서상 9과15(중2) < 9과16·17(중3) < 9과18(중2) < 9과20(중3)로 학년 배치가 코드 순서와 어긋남 — 2022 개정 원문과 대조 필요.)
11. **"혼합" 설명과 실제 로직**: 설명은 "국내 두 업체 중 유리한 쪽을 자동 선택"이지만 실제는 가격 비교가 아니라 고정 순서 [이지 유선 → 사이언스큐브 → 이지 나노 → 버니어 → 파스코]의 첫 취급 라인. 즉 이지 유선이 있으면 항상 이지 유선이고, 버니어·파스코로도 폴백 가능.
12. **버니어 유통 표현**: 탭1 카드 태그는 "국내 유통사 경유", 다른 곳은 "국내 총판 한국과학" — 표현이 섞여 있음.
13. **코드 주석 잔재**: `SENSORS` 주석은 "이지유선, 이지나노, 큐브유선, 큐브무선, 버니어, 파스코" 6열이라 하나 실제 데이터는 5열(큐브유선 제거됨). `LINE` 주석의 인덱스 설명(0~5)도 옛 구조. 동작에는 영향 없으나 재사용 시 열 위치 주의(사이언스큐브 무선 = 가격 3번째 값).
14. **업데이트 이력 "파스코 카탈로그 정가 20종"**: 가격표에서 파스코 값이 있는 행은 20개(자외선은 조도와 같은 제품·같은 가격 240,000 중복 계산), 본문 모델 나열은 19개.
15. **성취기준 텍스트 부재**: 탭 이름이 "수업 사례 · 성취기준"이지만 코드만 있음(위 한계 참조). 고유 코드 19개: 9과03-01, 9과03-02, 9과03-03, 9과04-01, 9과04-04, 9과05-02, 9과06-01, 9과06-02, 9과08-01, 9과08-02, 9과08-03, 9과12-01, 9과14-02, 9과15-01, 9과16-06, 9과17-01, 9과17-03, 9과18-02, 9과20-02.
